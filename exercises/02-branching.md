# Exercise 2: Branching

## Overview

This exercise focuses on how Git branches work: creating one, switching between them, and comparing them.

## What to practice

1. Create a new branch from where you are now.
2. Switch to that branch and make a small edit.
3. List your branches with `git branch` to see all of them at once.

## Goal

Be comfortable creating, switching to, and listing branches without having to remember a full history.
