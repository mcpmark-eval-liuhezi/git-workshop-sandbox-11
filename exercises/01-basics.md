# Exercise 1: Git Basics

## Overview

This first exercise walks you through the very foundations of Git: committing objects, viewing history, and reading back what you just did.

## What to practice

1. Make a small change to something (or create a new file) in this branch.
2. Stage that change with `git add`.
3. Commit it with a descriptive message, e.g.: `Add first exercise content`.
4. Verify the result with `git log` and `git show`.

## Goal

Leave a clean, sensible commit history that reads left to right like the story of your changes.
